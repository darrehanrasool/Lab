Project 9: Sentiment Analysis of Text
======================================
End-to-End Pipeline Guide:

1. Download raw IMDB sentiment dataset directly to disk:
   python src/data/make_dataset.py
   (Downloads and saves data/raw/sentiment.csv)

2. Perform text normalization, train/val/test splitting, and Sublinear TF-IDF extraction:
   python src/features/build_features.py
   (Saves data/processed/X_train.csv, X_val.csv, X_test.csv, y_train.csv, y_val.csv, y_test.csv, and vectorizer.joblib)

3. Train Logistic Regression model and log evaluation metrics:
   python src/models/train_model.py
   (Saves models/sentiment_model.joblib and generates accuracy.txt)

4. Generate full evaluation and text visual diagnostics:
   python src/visualization/visualize.py
   (Saves 8 figures to reports/figures/)

5. Test interactive sample sentiment classification via CLI:
   python src/models/predict_model.py

6. Run web application:
   cd web && python app.py
   Access in browser: http://127.0.0.1:5008
