9 Sentiment Analysis of Text
========================================================================
Course: CAI504C Machine Learning Lab • Semester I • IUST Kashmir
Clean Architecture: Production Jupyter Notebook Pipeline + Flask Web API

End-to-End Execution & Reproduction Guide:
------------------------------------------

1. Run the Full Machine Learning Pipeline (Interactive Jupyter Notebook):
   jupyter notebook notebooks/Sentiment_Analysis_Pipeline.ipynb
   (Executes end-to-end data ingestion, exploratory data analysis, zero-leakage 
    scaling, model training, cross-validation, and serializes production models)

2. Launch the Interactive Web Dashboard & REST API:
   python3 web/app.py
   (Starts the production Flask server with pre-loaded models at http://127.0.0.1:5009)

3. Review the Publication-Grade Master Learning Report:
   Open Sentiment_Report.pdf
   (Comprehensive 12-chapter textbook detailing theory, math derivations,
    and in-depth analysis of all 10 diagnostic figures)

4. Present Interactive Advanced Slides:
   Open Sentiment_Presentation.html in your browser
   (Interactive 13-slide stepper presentation for viva and defense)
