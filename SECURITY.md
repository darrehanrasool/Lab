# Security Policy

## Supported Versions
Security updates and bug fixes are applied to the latest release on the primary development branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability or potential data leakage vector within any model, script, or web serving endpoint:
1. Do **not** open a public issue.
2. Email the maintainer directly at `darrehanrasool@gmail.com` with a detailed proof-of-concept and steps to reproduce.
3. You will receive an initial response within 48 hours, followed by a coordinated patch and disclosure timeline.
