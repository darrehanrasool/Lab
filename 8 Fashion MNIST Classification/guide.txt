Project 8: Fashion-MNIST Classification
=========================================
End-to-End Pipeline Guide:

1. Download raw Fashion-MNIST dataset directly to disk:
   python src/data/make_dataset.py
   (Downloads, balances 15,000 images, and saves to data/raw/fashion_mnist.csv)

2. Perform pixel normalization, train/val/test splitting:
   python src/features/build_features.py
   (Saves data/processed/X_train.csv, X_val.csv, X_test.csv, y_train.csv, y_val.csv, y_test.csv, and scaler.joblib)

3. Train Multi-Layer Perceptron neural network model:
   python src/models/train_model.py
   (Saves models/fashion_mnist_model.joblib and generates accuracy.txt)

4. Generate full evaluation and image visual diagnostics:
   python src/visualization/visualize.py
   (Saves 8 figures to reports/figures/)

5. Test interactive sample classification via CLI:
   python src/models/predict_model.py

6. Run interactive web application:
   cd web && python app.py
   Access in browser: http://127.0.0.1:5007
