Project 10: Stock Prices Prediction
===================================
End-to-End Pipeline Guide:

1. Download raw historical daily OHLCV stock dataset:
   python src/data/make_dataset.py
   (Downloads and saves data/raw/stock_prices.csv)

2. Perform technical indicator feature engineering and chronological train/val/test splitting:
   python src/features/build_features.py
   (Saves data/processed/X_train.csv, X_val.csv, X_test.csv, y_train.csv, y_val.csv, y_test.csv, and scaler.joblib)

3. Train Random Forest Regression model and evaluate TimeSeriesSplit metrics:
   python src/models/train_model.py
   (Saves models/stock_model.joblib and generates accuracy.txt)

4. Generate full evaluation and time series visual diagnostics:
   python src/visualization/visualize.py
   (Saves 8 figures to reports/figures/)

5. Test interactive sample next-day price forecast via CLI:
   python src/models/predict_model.py

6. Run web application:
   cd web && python app.py
   Access in browser: http://127.0.0.1:5009
